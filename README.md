# 🏀 BasketballLife

> 此分支是陳偉振專屬的離線客製版，資料不會上傳至排行榜或 BL LIVE。想玩原版，請前往 [AKai0013/basketballlife](https://github.com/AKai0013/basketballlife) 或其正式網站。

**BasketballLife** 是一款可直接在瀏覽器遊玩的台灣籃球生涯模擬遊戲。

你將從 **16 歲、高一、HBL** 展開球員人生，經歷訓練、比賽、升學、選秀、職業合約、旅外、傷病、國家隊、場外人生與退休。天賦決定起點，但每一次選擇、傷病與機會，都可能讓同一名球員走出完全不同的生涯。

**目前正式版：V8.0**

🎮 **正式遊戲：** https://basketballlife.pages.dev/

---

## 🎮 一季怎麼進行？

**季初特訓 → 一般／特殊事件 → 健康與傷病 → 賽季結算 → 能力點分配 → 生涯抉擇**

你的選擇會影響球員能力與成長、球隊角色與上場時間、教練與球隊信任、心理與紀律、傷病與疲勞、職業市場與合約、旅外與國家隊機會、人際關係與場外人生，以及最終的生涯稱號與歷史地位。

V8.0 不再提前標示「冒險／平衡／穩健」或直接顯示成功率。很多選項都有自己的收益、代價與後續影響，不一定存在唯一正解。

## 🧬 世界 Seed

每一段生涯都有一組 **8 碼英文字母／數字 Seed**，約有 **36⁸ ≈ 2.8 兆種組合**。

Seed 會影響球員的先天天賦、自然成長、隱藏特質與部分固定命運。相同 Seed、相同位置與相同身材條件重新開始時，先天條件會保持一致，但玩家後續的選擇仍可能讓生涯走向完全不同。

| 隱藏等級 | 定位 |
|---|---|
| 👑 S+ | 世代級天賦，有機會挑戰最高舞台 |
| ⭐ S | 頂尖職業與旅外潛力 |
| 🔥 A | 優秀職業球員潛力 |
| 🏀 B | 最常見的正常職業生涯 |
| 🎲 C | 起點較困難，但仍有逆襲可能 |

> **Seed 決定起點，不決定結局。** 高天賦球員仍可能因傷病、錯誤選擇或市場變化跌落；普通球員也可能靠成長、機會與關鍵決策打出超越天賦的生涯。

## 👤 建立你的球員

V8.0 可以設定 PG／SG／SF／PF／C 五種位置，以及身高、臂展、慣用手、背號、台灣出生地與 64 位完整球員人物。

不同位置具有不同的合理身材範圍。身高與臂展會形成不同球風取向，不存在單純「越高越強」的設定。出生地主要作為球員背景與部分生涯故事依據，不直接提供能力加成。

### 64 位人物

V8.0 使用 **64 位完整人物插畫**。人物外觀與球員能力分離，不會因為選到特定人物就得到較好的 Seed 或能力；同一份生涯會沿用選定的人物至退休、公開生涯與紀念內容。

## 📊 八項球員能力

球員共有八項主要能力：**投射、終結、控球、傳球、防守、籃板、體能、球商**，單項最高為 **99**。

每項能力都有自己的自然成長條件。高能力區域的提升成本會逐漸增加，因此球員很難毫無代價地成為所有能力都頂尖的全能球員。

## 🎲 季初特訓

每個賽季開始時會進行特訓。玩家透過特訓取得成長資源，再自行決定投入哪些能力。

年輕球員通常擁有較大的成長空間；進入生涯後期後，球員會逐漸面對成長放緩、身體退化與健康管理。V8.0 同時保留天賦突破與晚成可能，因此球員的巔峰不一定出現在相同年齡。

## 🏀 生涯路線

球員從台灣高中籃球出發，可能經歷：

**HBL → 大專／其他發展路線 → 台灣職籃 → 日本／韓國／CBA → NBA G League → NBA**

不同生涯不一定會走遍所有聯盟。有些球員會成為台灣職籃明星，有些會長期旅外，有些能挑戰 NBA，也有人可能因傷病、市場或能力不足提早離開職業舞台。

## 🧑‍🤝‍🧑 球隊與人物關係

V8.0 強化生涯世界的延續性。球員可能與教練、經紀人、隊友、宿敵與伴侶建立持續多年的關係。

球隊也不再只是背景名稱，可能經歷爭冠、重建、教練更替、財務壓力、角色重新分配，以及外援與隊友異動。球員在球隊中的定位可能是板凳、輪替、第六人、先發、主力甚至球隊核心，並會隨表現與合約承諾改變。

## 🎭 事件與場外人生

V8.0 將事件分成一般事件、特殊事件、場外事件、醫療壓力與長期連鎖事件。

事件不再直接告訴玩家哪一個選項「最好」。某些高風險決定可能換來巨大收益，也可能留下長期代價；看似安全的選擇也不一定永遠是最佳解。部分重要決定會跨越多個賽季持續影響生涯。

## 🏥 疲勞、傷病與復出

球員會受到疲勞、舊傷與傷病影響，可能面對輕傷、中度傷勢、重大傷勢、手術、帶傷出賽、打針上場、限制上場時間、提前復出與完整休養。

硬撐並非只有懲罰。在某些情況下，帶傷出賽可能換來數據、球隊地位、英雄時刻或季後賽成果，但也可能提高惡化與長期傷害風險。

## 💼 合約與自由市場

進入職業後，合約會考慮薪資、年限、球隊角色、球員選項、球隊選項、市場評價、年齡、健康與過往表現。

拒絕一份合約不代表立即退休。當合約到期時，玩家可以繼續尋找市場機會，也可以在適當時機主動結束自己的職業生涯。

## 🇹🇼 國家隊

表現優秀的球員可能獲得國家隊機會。國家隊經歷會成為獨立於職業聯賽之外的重要生涯榮譽，也會保留在退休紀錄與公開生涯中；頂級國際賽成績會影響球員最終的歷史評價。

## 🏆 榮譽與生涯評價

職業生涯可能取得聯盟冠軍、年度 MVP、總冠軍賽 MVP、最佳防守球員、年度第一／第二隊、明星賽、得分王、助攻王、籃板王、國家隊榮譽、球衣退休與名人堂等成就。

退休後還會依整段生涯產生代表性的生涯稱號。

## ⚡ BL POWER

**BL POWER** 是 BasketballLife 用來綜合評價整段生涯的指標。

它不只看單一能力值，而會綜合考慮職涯產量、巔峰高度、主要榮譽、冠軍、國家隊、聯盟層級與其他生涯成果。

因此：**OVR 很高 ≠ BL POWER 一定最高。** 真正偉大的生涯仍需要把天賦轉換成實際成就。

## 🌱 每週 Seed 挑戰

除了普通生涯之外，V8.0 提供官方 **每週 Seed 挑戰**。

當週所有玩家使用相同的 Seed、位置、身高與臂展，在相同先天條件下比較最終生涯。每位玩家每週只保留自己的最高成績；挑戰結束後，冠軍與代表生涯會保留於歷屆紀錄。

## 🌐 公開生涯與排行榜

排行榜分成三個主要區域：

- **V8 現役榜**：收錄 V8.0 一般公開生涯。
- **每週 Seed 挑戰榜**：只收錄當週官方 Seed 挑戰生涯。
- **V7 傳奇榜**：永久保存 V7.50 時期已公開的歷史生涯。

V7 與 V8 不會互相覆蓋。排行榜主要顯示前 50 名，而玩家數與公開生涯總數會以資料庫中的完整紀錄統計；完整生涯資料只有在玩家實際點開某筆公開生涯時才會載入。

## 📡 BL LIVE

**BL LIVE** 是 BasketballLife 世界中的即時新聞區，會從公開生涯中挑選值得播報的重要成就，例如頂級聯盟冠軍、MVP／DPOY、NBA 重大突破、國家隊重要成績、名人堂與傳奇里程碑。一般小事件不會大量塞入 BL LIVE。

## ☁️ Online 與資料庫

BasketballLife 正式站部署於 **Cloudflare Pages**。

公開生涯、排行榜與 BL LIVE 使用 **Cloudflare Pages Functions ＋ D1**。排行榜採按需讀取與短期快取，不建立常駐 Realtime 監聽，以避免玩家只是停留在頁面上就持續產生大量即時訊息與不必要的資料流量。

V7.50 的既有公開生涯已轉入 D1，並永久保留於 V7 傳奇榜。

## 💾 存檔

進行中的個人生涯會自動保存在目前使用的瀏覽器。重新開啟網站後，可以透過 **繼續遊戲** 回到尚未完成的生涯。

請注意：

- 更換瀏覽器不會自動同步本機存檔。
- 無痕模式的資料可能在關閉後消失。
- 清除網站資料可能刪除本機生涯。
- 網站正常更新不會主動刪除既有存檔。

公開到排行榜的退休生涯則會保存於 Online 資料庫。

## 📰 退休

退休不是單純的 Game Over。

生涯結束後會整理最終生涯評價、BL POWER、巔峰 OVR、各聯盟表現、生涯總數據、主要榮譽、國家隊紀錄、逐季球隊軌跡、重要生涯轉折、名人堂結果、球衣退休與代表稱號，並產生完整的中文退休專題與紀念內容，讓每一次人生都有自己的結局。
